# 🌐 Portfolio

Welcome to my personal developer portfolio! This site showcases my projects, skills, and ways to get in touch. Built with **React.js** and styled using **Tailwind CSS**.


## ✨ Features

- ⚡️ Fast and modern UI built with **Next.js 15**
- 🎨 Responsive & dark mode-friendly design using **Tailwind CSS**
- 📂 Modular and clean code structure
- 🌓 Light/Dark theme toggle
- 📱 Fully responsive on all devices
